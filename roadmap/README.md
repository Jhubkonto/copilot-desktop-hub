# Nexy roadmaps

Roadmaps record scope, decisions, and verification evidence. They are not all descriptions of
currently shipped behavior; implementation remains the source of truth.

| Location | Meaning |
| --- | --- |
| [`roadmap-new/`](roadmap-new/) | Proposed, deferred, or superseded work that has not started. |
| [`roadmap-in-progress/`](roadmap-in-progress/) | Active work, partial implementation, or work awaiting manual/device validation. |
| [`roadmap-complete/`](roadmap-complete/) | Completed or superseded historical records with completion evidence. |
| [`bugs/`](bugs/) | Open and in-progress defect records. |

## Active milestone

**UI Unification — standardize the desktop and Android experience.** The primary plan is
